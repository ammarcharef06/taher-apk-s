## 🚀 عن المشروع
**Taher Accounting NG** هو الإصدار الثاني والمطور بالكامل من نظام المحاسبة السابق. تمت إعادة كتابته من الصفر ليعالج القيود التقنية السابقة ويوفر تجربة استخدام احترافية تشبه البرامج التجارية المدفوعة، ولكن **مجاناً وبدون قيود**.

صُمم هذا النظام خصيصاً ليلائم بيئة العمل الميدانية، حيث قد ينقطع الإنترنت في أي لحظة. جميع العمليات الحسابية والإدخالات تُحفظ فوراً على الجهاز، مما يضمن عدم ضياع أي بيانات.

## ✨ المميزات الرئيسية

### 🏢 إدارة متعددة الشركات (Multi-Tenant)
- **عزل تام للبيانات:** كل شركة (أو ورشة) لها قاعدة بياناتها المعزولة.
- **صلاحيات متقدمة:**
  - `Super Admin`: مدير النظام (أنت).
  - `Company Admin`: مالك الشركة (يرى كل شيء).
  - `Accountant`: محاسب (تقارير ومراجعة).
  - `Data Entry`: مدخل بيانات (إضافة حركات فقط).
  - `Client`: بوابة للعميل لرؤية فواتيره وتوقيعها.

### 💰 إدارة مالية دقيقة
- **الصندوق (Caisse):** تسجيل الدخول والخروج، حساب الرصيد التراكمي، وفلاتر بحث.
- **العمال والأجور:** حساب الأجر الأساسي، الإضافي، المكافآت، والاقتطاعات، مع ترحيل المتبقي تلقائياً للشهر القادم.
- **التسبيقات (Avances):** تتبع السلف مع تنبيهات ذكية للتسبيقات القديمة (أكثر من 30 يوماً).
- **الضمان الاجتماعي:** إدارة التصريحات والمدفوعات (CNAS / CASNOS).
- **المصاريف والمشتريات:** تصنيفها، حساب الرسوم (TVA)، وربطها بالصندوق.

### 📁 الأرشيف الذكي
- إنشاء وثيقة أرشيف تلقائياً مع كل حركة مالية.
- إرفاق صور الفواتير أو ملفات PDF مباشرة من كاميرا الهاتف.
- حفظ الملفات محلياً (IndexedDB) ومزامنتها سحابياً (Supabase Storage).

### 🔄 المزامنة التلقائية (Offline-First)
- العمل بدون إنترنت بشكل كامل.
- مزامنة صامتة في الخلفية عند توفر الشبكة.
- حل التعارضات (Conflict Resolution) تلقائياً لضمان عدم ضياع البيانات.

### 🌍 تعدد اللغات والطباعة
- دعم كامل للعربية (RTL)، الفرنسية (LTR)، والإنجليزية.
- طباعة احترافية للوصولات في نصف ورقة (A5) أو ربع ورقة لتوفير الورق.
- تصدير التقارير كملفات PDF.

## 🛠️ التقنيات المستخدمة

| الطبقة | التقنية | السبب |
| :--- | :--- | :--- |
| **الواجهة (Frontend)** | Vue 3 + Vite + TypeScript | سرعة، مرونة، وأداء عالي. |
| **التصميم (UI)** | TailwindCSS + Headless UI | تصميم متجاوب وسريع. |
| **إدارة الحالة** | Pinia | المتجر الرسمي لـ Vue. |
| **قاعدة البيانات المحلية** | Dexie.js (IndexedDB) | تعمل أوفلاين وتدعم الاستعلامات المعقدة. |
| **قاعدة البيانات السحابية** | Supabase (PostgreSQL) | مجانية، سريعة، وتدعم RLS للأمان. |
| **المزامنة (Sync)** | Custom Sync Engine | مزامنة ثنائية الاتجاه (Pull/Push) مع طابور للعمليات. |
| **تطبيق الأندرويد** | Capacitor 6 | تحويل الكود إلى APK أصلي. |
| **تطبيق الويندوز** | Tauri 2 | حجم صغير جداً (10MB) وأداء ممتاز. |
| **الاستضافة** | Vercel (ويب) + GitHub Actions (بناء) | مجاني 100%. |
